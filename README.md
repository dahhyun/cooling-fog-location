# cooling-fog-location
천안시 폭염 저감 시설의 최적 입지를 선정하는 데이터 분석 프로젝트입니다.

프로젝트 소개
이 프로젝트는 충청남도 천안시 노인 인구수가 많은 상위 3개 지역(청룡동, 성환읍, 신안동)에 폭염 취약 계층을 위한 최적의 쿨링포그 입지를 선정하기 위해 개발되었습니다. MCLP(Maximum Covering Location Problem)와 P-median 모델을 활용하여 수요 지점(노인 시설, 버스 정류장 등)과 공급 후보지(공원, 쉼터 등) 데이터를 분석하고, 두 모델의 결과를 병합하여 최종적인 최적 입지를 도출합니다.

데이터셋 구성
- raw_data/: 1차 가공을 마친 원본 데이터셋이 포함되어 있습니다.

- preprocessed_data/: 모델링에 바로 사용할 수 있도록 행정동별로 분리하여 재가공한 데이터셋이 저장됩니다.

- results/: MCLP, P-median 모델링 결과와 두 모델의 공통된 최종 입지 결과가 저장됩니다.

코드 및 분석 프로세스
01. preprocessing_data.ipynb
이 스크립트는 모델링에 필요한 데이터를 전처리하고, 행정동별로 데이터를 분리하여 preprocessed_data 폴더에 저장합니다.

02. MCLP.ipynb
이 스크립트는 최적의 입지를 찾기 위해 MCLP 모델을 실행합니다.

- 대상 지역: 천안시 노인 인구수 상위 3개 지역 (청룡동, 성환읍, 신안동)
- 수요 지점: 노인 시설, 노인 복지 시설, 경로당, 버스 정류장
 -후보 지점: 공원, 실외 운동 기구, 야외 휴게 쉼터, 무더위 쉼터
- 가중치: (전체 수요 지점 수 - 해당 수요 지점 수) / 전체 수요 지점 수
- 커버리지 반경: 500m
- 설치 개수: 5개

03. P-median.py
이 스크립트는 P-median 모델을 사용하여 최적 입지를 선정합니다.

- 가중치: MCLP 모델과 동일한 가중치를 사용합니다.
- 선정 방식: 가중치 합이 가장 높은 순으로 상위 5개 후보지를 선정합니다.

04. merge.py
이 스크립트는 MCLP.ipynb와 P-median.ipynb에서 도출된 결과를 병합하여 두 모델이 공통으로 선정한 최종 입지를 추출합니다. 또한, 최종 결과에 입지 후보지 파일의 주소 정보를 결합합니다.
